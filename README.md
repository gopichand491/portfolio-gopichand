## Getting Started

To run the project locally on your machine, follow these steps:

### Prerequisites

Ensure you have [Node.js](https://nodejs.org/) installed (v18+ recommended).

### Installation

1. Clone the repository:
   ```bash
   git clone https://github.com/gopichand491/portfolio-gopichand.git
   cd portfolio-gopichand
   ```

2. Install dependencies:
   ```bash
   npm install
   ```

### Development Server

Run the local development server with hot-reload:
```bash
npm run dev
```

### Production Build

Build the production-ready static assets to the `dist/` directory:
```bash
npm run build
```

Preview the production build locally:
```bash
npm run preview
```
